# GHCWSV / GHCWPS 1.0 验证记录

日期：2026-09-12～2026-09-13。硬件：RTX4060 Laptop，sm_89。
测试在独立临时目录内执行；未修改已有筛选队列，未连接或发布网络项目。

## 构建

- CUDA13.3，Windows MSVC14.51；Linux 在 Ubuntu22.04/GCC11 容器构建。
- 两个平台均包含 sm_86、sm_89、sm_100、sm_120 cubin，已用 cuobjdump 检查。
- Linux 引用 glibc 符号的最高版本为 GLIBC_2.34；静态链接 CUDA runtime、libstdc++、libgcc。
- Linux GHCWSV 素数流水线搭配 primesieve12.10，优先从旁边lib目录加载并检查版本。
- 不声称所有 GPU 架构均已实机验证；实际 GPU 测试只在本机 sm_89 上进行。
- CMake 配置和构建在 WSL 验证成功。

## 正确性

- Windows/WSL各56个 PRP CPU参考样例与 Python pow 的结果比对。
- GPU上8种表达式 × 3种 witness，完整余数与 cpp_int/Python参考核对。
  witness整除候选的无效情况按预期拒绝。
- GHCWPS部分断点：GPU写入→CPU恢复、CPU写入→GPU恢复，余数一致。
- 拒绝截断、SHA错误、参数或witness不匹配、错误项目魔数的断点。
- GHCWSV对6种b、两种符号、n=2..1300：auto/direct/transform/CPU输出一致。
- 系数预计算路径与直接GPU及CPU参考输出一致。
- GPU自检252组完整模积和逆指数变换目标，覆盖接近2^62的p及32位参数边界。
- 大p区间筛选另与独立 Python 模运算对照。
- WSL筛法 SIGINT 后续筛结果与不间断运行字节一致。
- Windows两个程序均在各自独立隐藏控制台中真实发送 Ctrl+C：退出码130，
  保存文件摘要有效，后续恢复运行成功。未向用户已有控制台广播信号。
- Windows/WSL各验证2100001候选、跨多次核函数的完整覆盖：1400001个剩余，
  与独立模3公式一致，没有因中间分块漏掉候选。
- 转换脚本验证输入摘要与行数，导出55个样例候选；未上传服务器。
- 最终Linux兼容构建完整检验 `2^196608*196608^2+1 = 9*2^196640+1`，
  GHCWPS与GSRPS得到相同的校验和 `87860748:516889655`。

这些测试提供回归证据，不构成对所有输入无bug的数学证明。Fermat PRP结果仍需独立验证。

## 筛法性能

WSL、2个素数生成线程，p区间(10^12,10^12+2×10^8]；固定 n 集合，
每项两次运行取平均端到端墙钟时间。GNCWSV使用相同n集合，但检验的是普通
`n*b^n+1`，因此属于不同数族的算法成本对照，不是相同整数的筛选。

| b | 候选数 | GHCWSV auto | GHCWSV direct | GNCWSV |
|---|---:|---:|---:|---:|
| 2 | 2000 | 3.397s | 6.606s | 2.407s |
| 65537 | 1000 | 2.988s | 8.430s | 2.211s |

- b=2系数预计算比直接路径快约1.94倍；相对GNCWSV耗时约1.41倍。
- b=65537变换路径比直接路径快约2.82倍；相对GNCWSV耗时约1.35倍。
- b=7的早期对照中变换分组不划算，因此auto对较小b优先直接计算；
  `--algorithm transform`仍可用于特定输入实测，所有非互素p有完整回退。
- 不把短区间启动耗时、不同候选密度或不同p区间的数字当成固定加速比。

## PRP性能

约10万位，推进30000 bit：最终构建 GHCWPS5.08秒、GFPPS5.20秒，NTT长度均65536。
前者为 `7^118330*118330^7+1`，后者为 `7777*25206!+1`；同位数级，非相同整数。

完整相同整数 `2^196608*196608^2+1` 的开发构建对照：GHCWPS22.50秒，
GSRPS13.46秒，余数校验和相同。最终兼容构建复测为GHCWPS27.37秒、
GSRPS16.11秒，约1.70倍耗时；校验和仍一致。
最终复测的原始计时见 `validation/RELEASE_PERFORMANCE.json`。
笔记本频率、功耗状态、编译环境和NTT长度会影响结果，不承诺固定倍数。

## 边界

- 不支持任意双幂乘积：必须恰为 b^n*n^b±1。
- 单个筛选文件固定b和符号；现有GNCWSV/GSRSV文件不应直接改扩展名混用。
- 筛选边界以文件头及SHA校验为准，不以文件名所写的1eXX为准。
- 仅加入到Personal Tools；未覆盖旧程序，当时未上传GitHub或部署服务器/5090。
