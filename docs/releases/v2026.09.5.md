# CUDA PRP: sieve and check tools — v2026.09.5

This release adds GFPPS 1.0 and promotes the tested fused-carry GFPS path to
version 4.4. Component versions are independent of the suite tag.

| Component | Version |
| --- | ---: |
| GFPS | 4.4 |
| GSRPS | 2.3 |
| GFPPS | 1.0 |
| GFNSV | 1.0 |
| GSRSV | 2.0 |
| GNCWSV | 1.0 |

## GFPS 4.4

- Fuses carry propagation, convergence checking, and RNS export in checked
  carry batches at 100% duty. Failures remain latched; failed batches are
  restored and replayed through the independent adaptive path.
- Keeps the existing exact CRT/base limits, special balanced residue, and
  portable checkpoint format. Input `n>20` remains unsupported.
- Preserves non-fused adaptive paths for `--batch-bits 0`, `--reference-mode`,
  and duty below 100. `GFPS_DISABLE_FUSED_CARRY=1` disables the new fusion for
  direct comparisons with the previous checked-batch normalization.
- Same-session alternating 30,000-bit measurements on an RTX 4060 Laptop GPU
  reduced median time by 21.7% for the four-prime case and 34.9% for the
  three-prime case. These are case-specific measurements, not universal gains.
- The complete million-digit `1814570322984178^65536+1` run took 265.811 s of
  exponentiation. Five anchors, including the final state, matched the earlier
  validated GFPS 4.1 run byte for byte.

## GFPPS 1.0

- Fermat PRP checks for `k*n!+/-1` and `k*n#+/-1`; `n#` means all primes not
  exceeding n, not the first n primes.
- General integer Montgomery reduction and two-prime NTT convolution, with
  no FP64 requirement for GPU arithmetic.
- Explicit `--checkpoint FILE`, Ctrl+C save, SHA-256 integrity validation, and
  Windows/Linux cross-resume. **No checkpoint file is created when the option
  is omitted.** Default progress and periodic saves are every 100,000 bits.
- Keeps the user-supplied 1.0 banner in help/no-argument output, using portable
  UTF-8 border literals for Windows nvcc compatibility.
- `PARTIAL` and `INTERRUPTED` are incomplete states and must not be treated as
  composite results. Small tests can request independent `--verify-cpp-int`.
- 29 known primorial samples passed complete checks on both systems, with
  identical state pairs and independent GMP full repetitions. The largest
  sample has 45,259 decimal digits.
- Million-digit timing remains a 29–30 minute estimate from checked prefixes,
  **not a completed million-digit validation**. There is no PRPNet adapter,
  task queue, duty throttle, or deterministic proof generator in GFPPS 1.0.

## Downloads and verification

The final publication builds passed 38 runtime checks on `sm_89`. In particular,
GFPS 4.4 on Windows completed the million-digit known PRP in 284.049 s of
exponentiation (286.203 s process wall time); all five saved anchors matched
the validated Linux reference byte for byte. The two new components account
for 16 freshly compiled binaries; the other 32 are hash-verified unchanged
artifacts from v2026.09.4. These timings are measurements of specific runs,
not a controlled Windows-versus-Linux comparison.

There are twelve component/platform archives (six tools, Linux and Windows),
plus a source archive, `manifest.json`, and `SHA256SUMS`: **15 release assets**.
Each component archive includes `sm_86`, `sm_89`, `sm_100`, and `sm_120` native
binaries for its platform. Choose the filename matching your GPU.

Runtime evidence is from an RTX 4060 Laptop (`sm_89`). Other architecture
targets are cross-compiled and cubin-inspected, not runtime-tested on matching
hardware. Consult each artifact's manifest/BUILDINFO for its exact source and
binary hashes, compiler flags, and runtime test evidence. Verify downloaded
archives against `SHA256SUMS` before running them.

All checker hits remain probable primes, not deterministic primality proofs.
Independently verify important hits and retain checkpoints and logs. See
[validation](https://github.com/AstralPrisma/cuda-PRP-sieve-and-check-tools/blob/v2026.09.5/docs/validation-2026-09.md)
and [correctness](https://github.com/AstralPrisma/cuda-PRP-sieve-and-check-tools/blob/v2026.09.5/docs/correctness.md) for
test coverage and limitations. GSRPS, GFNSV, GSRSV, and GNCWSV keep their
previous component versions in this release.
