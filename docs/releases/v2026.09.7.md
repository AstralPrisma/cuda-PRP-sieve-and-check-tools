# CUDA PRP: sieve and check tools — v2026.09.7

GFNSV advances to **1.1**. The other component versions remain GFPS 4.4,
GSRPS 2.3, GFPPS 1.0, GSRSV 2.0, and GNCWSV 1.0.

## GFNSV 1.1

- A single v4 GFN/ABC/base/expression file holds ordered survivors, bounded
  continuation metadata, and count/SHA-256 checks. Ctrl+C saves after the
  current GPU batch; the file alone resumes on Windows or Linux.
- Factor logging with `-O` is optional. The main checkpoint does not require
  a `.sieve-state` companion or historical factor table. Default CPU checks
  still verify newly retained mathematical factors before saving.
- Short options include `-n`, `-b`, `-B`, `-p`, `-P`, `-w`, `-i`, `-o`, `-f`,
  `-O`, and `-q`. Progress includes survivors, elapsed time, and a fixed-bound
  ETA. `--progress-seconds` controls the reporting interval.
- Combined `-4`/`-5`/`-6` limits stop on low removal efficiency. They override
  `-P` with the supported maximum, reset timers on resume, and save the
  completed prefix as the achieved depth on normal efficiency stop.
- Complete CUDA v3 files and validated legacy GFN/ABC plus v3 companion pairs
  remain migration inputs. Invalid v4 data never silently uses an old sidecar.
- Both platform archives include `scripts/gfnsv_to_cands.py` and
  `scripts/gfnsv_queue.py` for offline task conversion using Python 3.10+.
  Conversion validates completion, defaults to n=16, supports a write-free
  dry-run, rejects mixed/conflicting tasks, and does not upload or change input.

See the [GFNSV README](https://github.com/AstralPrisma/cuda-PRP-sieve-and-check-tools/blob/v2026.09.7/GFNSV/README.md)
for command examples, migration rules, and recovery boundaries.

## Validation and binary provenance

The final GFNSV validation includes 141 deterministic C++ compact-codec checks,
45 cross-language fixtures, 47 CLI integration cases, and 82 Python tests per
platform (Windows: 80 passed / 2 skipped; WSL: 81 passed / 1 skipped). Real
Windows/Linux interruptions saved valid partial files, and standalone copies
resumed in the opposite operating system with the same survivors as fresh
runs. Converter and GFPS wrapper queue-preparation checks also passed.

Eight updated GFNSV binaries cover Windows/Linux and `sm_86`, `sm_89`,
`sm_100`, and `sm_120`. Their hashes, executable formats, and native cubin
targets were checked. Only `sm_89` was GPU-runtime-tested on an RTX 4060
Laptop GPU; the other targets are cross-compiled.

The other **40 executables are byte-identical to v2026.09.6**, with unchanged
source/header hashes. Their prior compiler and runtime-test evidence is
retained and their reuse recorded in `manifest.json` and `BUILDINFO.txt`.
This release does not claim that all 48 executables were rebuilt or that the
other tools received a new full-length numeric-validation round.

Downloads contain twelve component/platform archives, one source archive,
`manifest.json`, and `SHA256SUMS` (15 assets). GFNSV archives are named
`gfnsv-1.1-<platform>-cuda13.3`; the other component names and versions remain
unchanged. The source archive contains source, documentation, and portable
CPU tests, with no executables, private paths, runtime logs, or user data.

This publication updates GitHub source and Release downloads only. Separate
website downloads and externally hosted ZIP bundles are unchanged.

Sieve survivors and PRP hits are not deterministic primality proofs. A compact
file's checksum detects damage but does not prove an untrusted producer's
sieving history. Independently verify important results. See
[validation](https://github.com/AstralPrisma/cuda-PRP-sieve-and-check-tools/blob/v2026.09.7/docs/validation-2026-09.md)
and [correctness](https://github.com/AstralPrisma/cuda-PRP-sieve-and-check-tools/blob/v2026.09.7/docs/correctness.md).
