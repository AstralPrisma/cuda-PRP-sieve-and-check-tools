# v2026.09.11 — GHCWSV 1.1, both signs in one sieve

GHCWSV now accepts `--sign both` (alias `--sign +/-1`) for `b^n*n^b±1`.
Prime generation and modular powers/products are shared; each sign retains
its own live bit and independently verified factor. Removing one sign never
removes the other candidate for the same n.

```sh
GHCWSV -b 7 -n 2 -N 100000 --sign both -P 1e8 -o hc7_both.txt
GHCWSV -i hc7_both.txt -P 1e9 -o hc7_both.txt
python scripts/ghcw_to_cands.py hc7_both.txt --out-dir tasks --network
```

Both-sign snapshots use checksummed v2 rows `n -1` / `n +1`, ordered by n
then sign. Resume needs only that file; the optional factor log is not needed.
`survivors` counts expressions, with separate `plus` and `minus` counters.

Old v1 single-sign files remain readable and are still written in v1 format.
A single-sign snapshot cannot be expanded to both signs by changing an option:
the absent sign has no evidence of having reached the saved sieve depth.
Version1.0 does not read v2 snapshots. The converter understands both versions
and can export all surviving signs or filter with `--sign=+1` / `--sign=-1`.

## Builds and validation

Windows x64 and Ubuntu22.04-compatible Linux x86-64 packages each contain
native sm_86, sm_89, sm_100 and sm_120 builds. All eight final binaries were
checked for target, UTF-8 banner, version and CPU-reference behavior.
Only sm_89 was GPU-tested, under Windows and WSL on one RTX4060 Laptop.

Validation covers independent modular reference results, auto/direct/transform
paths, coefficients, near-2^62 prime and uint32 n boundaries, sign-preserving
resume, corrupt files, small prime candidates equal to trial divisors,
2,100,001 distinct-n chunking, and real CTRL_BREAK/SIGINT resume equivalence.
Six old/new single-sign snapshot pairs match byte-for-byte.
See `GHCWSV/VALIDATION_both_20260913.md` for scope and raw summaries.

This release contains only newly built GHCWSV packages and the full tagged
source archive. GHCWPS1.0 remains available from
[v2026.09.10](https://github.com/AstralPrisma/cuda-PRP-sieve-and-check-tools/releases/tag/v2026.09.10);
GFPS4.4, GSRPS2.3, GFPPS1.0, GFNSV1.1, GSRSV2.1 and GNCWSV1.0 are unchanged
from their previously linked packages. No client or production-server update
is required for these survivor-to-task files.

Sieve survivors are not primality results. Independently verify important PRPs.
