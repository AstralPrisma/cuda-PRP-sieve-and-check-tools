## Changes

- **GFPS 4.1:** half-length negacyclic NTT, DIF/DIT and shared-memory fusion,
  checked carry batches with adaptive replay, and improved Windows duty-cycle
  throttling. Existing checkpoint interfaces are retained.
- **GSRPS 2.3:** condition-checked weighted scans and compact carry reduction,
  with exact fallback for unsupported arithmetic shapes. Existing tuning and
  arithmetic-checkpoint controls remain available.
- **GFNSV CUDA 1.0:** a new integer CUDA sieve for even bases of `b^(2^n)+1`,
  paired-root enumeration and default CPU factor checks. Ctrl+C saves a
  SHA-256-protected state after the active GPU batch; resume from that file with
  `--resume --out cand.txt`. Completed files may resume with a larger `--pmax`.
  The older CPU GFNSV is not included.
- GFPS documentation now lists exact CRT-limited maximum even bases for
  `n=10..20`, followed by a single `>20: Not supported` row. These are input
  bounds, not performance or memory guarantees.

## Downloads and validation

Each component has separate Windows x64 ZIP and Linux x86-64 tar.xz downloads,
containing native `sm_86`, `sm_89`, `sm_100`, and `sm_120` binaries. Choose the
architecture matching your GPU; the files are not universal GPU executables.

The current implementations passed the arithmetic, checkpoint, cross-platform
and sieve tests described in [the validation record](../validation-2026-09.md).
Only `sm_89` has runtime evidence on this machine (RTX 4060 Laptop GPU); the
other targets are cross-compiled and inspected, not tested on matching GPUs.
For the exact uploaded artifact's status and evidence, read `BUILDINFO.txt`
and `manifest.json`. Their compiler, flags, source/header hashes and binary
hashes are checked against explicit build provenance during packaging.

The public builds omit private path-bearing debug information. Unchanged
GSRSV/GNCWSV binaries retain their verified previous-release provenance.
Linux uses the recorded Ubuntu 24.04/GCC 13.3 build environment; Windows uses
MSVC and CUDA 13.3. These are not guaranteed to run on older Linux libraries
or drivers. See each component README and `BUILDINFO.txt` for requirements.

`SHA256SUMS` covers the ten binary packages, exact source archive and manifest.
The source archive corresponds to this release's tag; binaries are not
committed to the source repository.

**PRP is not a deterministic primality proof.** Verify valuable hits
independently. Sieve survivors are candidates, not a primality claim.
