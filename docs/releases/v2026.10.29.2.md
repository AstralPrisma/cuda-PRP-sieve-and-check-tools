# v2026.10.29.2 — GFPDIVSV1.1 CUDA

This release updates GFPDIVSV only. Other tools, including the generic public
GFPS, remain unchanged. Private RGFPS/RGFNSV and a stand-alone host-only sieve
are not included.

- Persistent primesieve iterators remove per-array reinitialization overhead.
- Bounded, ordered producer queues can overlap prime generation with CUDA.
- Default auto mode times identical real-prime samples with independent factor
  verification on disposable survivor states, selects batching, and caches a
  hardware/task-specific profile. Trial work never advances the true frontier.
- Supplier counts grow only on measured starvation. Less than3% improvement
  causes rollback/freeze; manual resource overrides remain available.
- Snapshot format`GFPDIVSV 1`, checked resume, both signs, factor verification
  and offline task converters remain compatible.

Windows and Linux packages each provide native sm_86/89/100/120 binaries.
Physical GPU validation is limited to RTX4060 Laptop sm_89 on Windows and WSL;
other targets receive compilation, architecture and non-GPU startup checks only.
See component validation records and package manifests for exact binary hashes.

新版默认自适应批量和质数供数，不要求手动增加libprimesieve线程；任务规模、
筛深和硬件不同，收益也不同。调优不改变真实候选与断点，不修改筛分积分规则。
仅更新CUDA筛子，不发布独立CPU版，不改动其他项目、网站或客户端。
