# CUDA PRP: sieve and check tools — v2026.09.8

This release updates **GSRSV to 2.1**. GFPS 4.4, GSRPS 2.3, GFPPS 1.0,
GFNSV 1.1 and GNCWSV 1.0 keep their current versions and existing binaries.

## Faster factorial and primorial sieving

GSRSV now directly multiplies packed raw product chunks with exact Montgomery
reduction, using a short pre-seed correction instead of repeating `% p` and
domain conversion for every chunk. A product-only low-word carry simplification
removes additional arithmetic. The `b^n` path and all CLI/file/resume interfaces
remain unchanged. The primorial example now correctly uses prime endpoint 997.

Measured RTX 4060 Laptop GPU fixed-range, two-stream comparisons gave roughly
**3.50x** throughput for 25206! and **3.29x** for 230563#, with identical
survivors. Full conditions, mathematical bounds and test coverage are in
[GSRSV validation](../../GSRSV/VALIDATION_v2.1.md).

Windows and Linux sm_89 were checked on real hardware. sm_86, sm_100 and sm_120
are cross-compiled, not claimed to have been runtime-tested on those GPUs.
The manifest records exact source/header/binary hashes and compiler provenance.

All twelve component/platform archives, the full source archive, manifest and
SHA256SUMS remain available. Only eight GSRSV executables are rebuilt; the other
forty executable files are reused byte-for-byte from v2026.09.7 after matching
their source/header hashes. Refreshed archive metadata may change archive bytes.

PRPNet website client bundles are being kept separate from sieve distribution:
sieves remain in GitHub Releases, while website client ZIPs omit sieve programs
and sieve source. No project website is redeployed as part of this release.

A PRP is not a primality proof, and a sieve output is only a list of survivors.
See [correctness](../correctness.md) before relying on computational results.
