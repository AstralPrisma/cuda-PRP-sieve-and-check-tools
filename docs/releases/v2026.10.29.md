# v2026.10.29

## Updated components

- **CSPS1.0**, newly public: CUDA Fermat PRP checks for consecutive/alternate
  Catena Siderum power products, with strict construction and checkpoints.
- **CSSV1.3**, newly public: CPU/CUDA sieving, both signs, exact scientific
  sieve bounds, progress, safe checkpoints and checked candidate conversion.
- **GFPPS1.1**: factorial/primorial multiplication and exact single-factor
  removal. Legacy `GFPPS001` checkpoints are retained; quotient jobs use
  `GFPPS002`. New `--capabilities` is a CPU-only metadata command.
- **GPRSV2.3**, **GHCWSV1.3**: previously validated general-purpose scheduling
  and prime-generation updates. These are not universal performance claims.

Each updated CUDA program is packaged for Windows/Linux x86-64 with separate
sm_86, sm_89, sm_100 and sm_120 native binaries. CSPS/CSSV binaries may be
reused byte-for-byte from their validated2026-10-18 build when all source/header
hashes match. Build/startup coverage and physical-GPU coverage are recorded
separately in each archive; compilation does not establish hardware correctness.

GFPS stays the **generic** checker with variable n, not the fixed-n16 private
specialization. Its4.5 arithmetic/source is unchanged. Other unchanged
components retain their prior release assets.

## Dependencies and validation

Official Linux GFPPS1.1 builds link GNU GMP6.3.0 statically for host-only
construction/inversion. The corresponding upstream source and copyright
files accompany the release. No extra GMP executable or fixed helper path
is required. Windows GFPPS uses portable Boost construction and CUDA checking.

Sieve survivors are not primes, and a Fermat PRP hit still needs independent
primality proof. Partial benchmarks, interrupted jobs, malformed output and
execution errors must never be converted to composite results.
