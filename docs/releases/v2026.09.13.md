# v2026.09.13

- GFPS4.5 keeps the general `b^(2^n)+1` interface and checkpoint format. Large-base
  reciprocal division skips a leading quotient digit that is provably zero.
- GHCWPS1.2 supports15/18/21-bit plans with exact coefficient bounds, separate
  checkpoint tags and device-specific selection.21-bit is enabled automatically
  only in measured sm89 transform-reduction intervals; it is not a universal
  replacement and is rejected when unsafe for the requested modulus/witness.
- GNCWSV1.2.0 shares prime generation across multiple modes, selects fast44 by
  actual internal chunk bounds and tunes sparse coordinator groups. Existing
  factor verification and common completed-prime checkpoint boundaries remain.

Representative RTX4060 results: general GFPS about5–6% higher throughput on tested
million-digit inputs; GHCWPS about40–42% on two complete189035-digit examples
where NTT length halves; GNCWSV about19–21% on tested sparse b77 continuations.
These are workload-specific results, not promised gains for all candidates.

Windows and Ubuntu22.04-compatible Linux x86-64 packages provide native sm86,89,
100 and120 targets. Package build records distinguish physical GPU validation
from compile/help-only checks. Checksums, old checkpoint resume, malformed-state
rejection and independent small arithmetic references are retained.

Only these three components are updated. Existing downloads for other tools
remain available in earlier releases. PRP results are not primality proofs.
