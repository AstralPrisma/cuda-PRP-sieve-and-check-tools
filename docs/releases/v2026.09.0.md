# Initial public release - v2026.09.0

This release publishes the source of four CUDA prime-search tools in one
repository:

- GFPS 4.0
- GSRPS 2.0
- GSRSV 2.0
- GNCWSV 1.0

Linux x86-64 and Windows x64 packages are provided separately. Every component
package contains native `sm_86`, `sm_89`, `sm_100`, and `sm_120` executables
built with CUDA 13.3. The binaries contain native cubins and no universal PTX
fallback.

## Validation status

- All 32 `(tool, operating system, SM target)` binaries compiled successfully,
  and `cuobjdump --list-elf` matched every filename to its embedded cubin.
- Linux and Windows `sm_89` smoke suites passed on an NVIDIA GeForce RTX 4060
  Laptop GPU.
- Ten public GSRPS PRPs were checked completely on both operating systems. All
  20 checks returned `PRP` and the same final checksum `1:1`.
- `604832956^65536+1` completed a full GFPS base-2 Fermat PRP check on both
  operating systems. Both returned `result_is_one=yes` with
  `hash64=0xf2e5ecb6ac7e9a7b`.
- GSRSV and GNCWSV were each run on both operating systems through
  `p=99,999,989` using 5,761,454 primes and CPU verification of every reported
  factor. Survivor files and removed-expression sets matched.

Only `sm_89` has been runtime-tested for this release. The other targets were
cross-compiled and inspected but require testing on matching hardware.

## Important result semantics

GFPS and GSRPS perform Fermat probable-prime tests. A passing result is a PRP,
not a deterministic primality proof. Recheck valuable hits independently and
use appropriate proof software before reporting a prime.

See the repository README, component READMEs, `docs/correctness.md`, and the
package `BUILDINFO.txt` files for build and usage details.
