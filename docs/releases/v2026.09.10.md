# v2026.09.10 — Hyper Cullen / Woodall tools

Adds GHCWSV 1.0 (siever) and GHCWPS 1.0 (checker) for `b^n*n^b±1`.
Other component versions remain GFPS 4.4, GSRPS 2.3, GFPPS 1.0, GFNSV 1.1,
GSRSV 2.1 and GNCWSV 1.0. Their binaries are unchanged and available in
[v2026.09.9](https://github.com/AstralPrisma/cuda-PRP-sieve-and-check-tools/releases/tag/v2026.09.9).

## New artifacts

Each new tool has Windows x64 ZIP and Ubuntu22.04-compatible Linux x86-64
tar.xz packages, containing four separate native builds: sm_86, sm_89,
sm_100 and sm_120. Select the target matching the actual CUDA capability.
Linux C++/GCC/CUDA runtimes are static; glibc remains dynamic. GHCWSV also
includes the optional primesieve12.10 library and its BSD license.

The GHCWSV banner prints at main entry. GHCWPS prints the banner only on
help/usage, without adding artwork to normal machine-readable check output.
Both initialize the Windows console for UTF-8; explicit UTF-8 byte literals
keep the user's artwork independent of the compiler source codepage.

`GHCWSV/scripts/ghcw_to_cands.py` validates the authenticated survivor file.
Its default mode emits single-expression files; `--network` emits the
type-header format used by the Prime Seeker GHCWPS network project.
The converter performs no network writes.

## Validation boundaries

The prior arithmetic build was tested on RTX4060 Laptop, with independent
small-integer results, CPU/GPU resume, tamper rejection, SIGINT and direct vs
transformed sieving. See the component VALIDATION.md for the exact scope.
This release rebuild only connects the banners and changes their encoding;
all sixteen artifacts were inspected for native cubin target and exercised
for help/version, UTF-8 and CPU-only reference behavior. No GPU kernels were
run for these final rebuilt binaries. Their GPU runtime status is explicitly
not-tested; prior arithmetic evidence is not relabeled as a new binary test.

PRP is not a primality proof. Independently verify important results.
