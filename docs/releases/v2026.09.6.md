# CUDA PRP: sieve and check tools — v2026.09.6

This rebuild fixes Windows console banner encoding in all six tools. Component
versions are unchanged: GFPS 4.4, GSRPS 2.3, GFPPS 1.0, GFNSV 1.0, GSRSV 2.0,
and GNCWSV 1.0.

- Console output temporarily uses UTF-8 and restores the original output
  codepage on normal exit, including help paths using `std::exit`. Input
  codepage is unchanged; manual `chcp` is unnecessary.
- Redirected output remains UTF-8, compatible with existing Python clients and
  log files. No PRP arithmetic, sieve logic, or checkpoint format changes.
- Every component includes its required `console_utf8.hpp` source header.
  Linux initialization is a no-op. Both platforms are rebuilt from this tag.

The Windows `sm_89` executables passed 54 help-output cases across real console
codepages 936, 437, and 65001, with stdout redirected or both streams redirected
as well. All 18 full screen-buffer comparisons matched UTF-8 file output.
These are output-handling tests, not new full-length mathematical validation.
Forced process termination cannot run normal codepage cleanup.

The exact `sm_89` binaries also passed short GPU smoke regressions on Windows
and Linux, including checker selftests/reference checks, GFPPS checkpoint
continuation, and sieve survivor comparisons against independent Python
integer calculations. Full-length million-digit PRP runs were not repeated
for this display-only rebuild.

Downloads retain twelve component/platform archives, a source archive,
`manifest.json`, and `SHA256SUMS` (15 assets). Each component/platform archive
contains `sm_86`, `sm_89`, `sm_100`, and `sm_120`. Check the manifest and BUILDINFO
for exact compiler, source, binary hashes, and test evidence. Non-`sm_89` targets
are cross-compiled; no matching-hardware runtime validation is claimed.

Checker hits remain probable primes, not deterministic primality proofs.
Independently verify important results. Numerical test history is documented in
[validation](https://github.com/AstralPrisma/cuda-PRP-sieve-and-check-tools/blob/v2026.09.6/docs/validation-2026-09.md)
and [correctness](https://github.com/AstralPrisma/cuda-PRP-sieve-and-check-tools/blob/v2026.09.6/docs/correctness.md).
