# GFPPS 已知 primorial 样本测试

29 个不同的 `k*n#±1` 样本在 Linux 和 Windows 共完成 58 次完整 Fermat 检查。
全部结果为 PRP、余数 1；29 对完整 checkpoint 逐字节相同。
另外使用独立 GMP 构造 N 并进行 29 次完整模幂复算，全部余数、模数哈希和存储状态相符。
这验证了当前程序的计算结果，不是在 GFPPS 中重新生成确定性素数证明。

原始 AP-4 列表的第 3 项不属于本表：原记录是
[`263093407*2^99901-1`](https://t5k.org/primes/page.php?id=134415)，不是 primorial 表达式。

时间为各次 GPU 指数执行时间，不含模数构造与初始化，不是与其它程序的同条件性能排名。
测试期间 CPU 有其它 PRST 负载；Windows 测试期间还并行进行单线程 GMP 校验。
